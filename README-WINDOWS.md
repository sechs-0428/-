# Windows版 ケアマネ業務管理

Windows 10/11（64ビット）にインストールして使うソフトです。各PCに同じソフトを入れ、共有元の1台でデータを保存します。Excelを起動せずに利用できます。

## インストールと初回設定

1. `release/` の `CareManager Setup … .exe` を実行し、インストール先を選びます。
2. 共有元のPCでソフトを起動し、接続画面から「このPCを共有元にする」を選びます。事業所内で共有する場合は共有を有効にします。
3. 最初の管理者アカウントを作成します。パスワードは他の職員と共用せず、管理画面から職員ごとのアカウントを作成します。
4. 共有元に表示された `http://192.168.x.x:43180` などの接続先を、他のPCの「共有元に接続する」画面に入力します。
5. 各職員のアカウントでログインします。

共有元のソフトを終了したり、PCをスリープしたりすると、他のPCから接続できなくなります。勤務中は共有元を起動しておいてください。接続先には事業所内のIPv4アドレスまたは `localhost` を指定できます。

共有接続ができない場合は、共有元のソフトが起動していること、共有設定が有効であること、接続先IPとポートが正しいことを確認してください。Windows Defender ファイアウォールでは信頼できる事業所内のプライベートネットワークに限定して、このソフトの受信通信を許可します。既定ポートは `43180` です。IPアドレスが変わる環境では、共有元に固定IPを設定するか、ルーターのDHCP予約を利用してください。

## 保存先とバックアップ

共有元のデータは Electron のユーザーデータフォルダー内の `CareManager.sqlite` に保存されます。通常は `%APPDATA%\CareManager\` 配下です。接続画面に表示される保存先を確認してください。利用者PCには接続設定のみを保存します。

管理者は事業所設定の「バックアップを保存」から、利用者・プラン・事業所設定をJSONファイルに保存できます。ログインアカウントと過去の操作履歴は含みません。バックアップには利用者情報が含まれるため、事業所で管理する保存先を指定してください。共有データベースをエクスプローラーの共有フォルダーやOneDrive上へ直接置かず、ソフトの共有接続を利用してください。

復元するときは、新しい共有元のPCで事業所と管理者を登録し、利用者・プランが未登録の状態で、事業所設定の「バックアップから復元」からJSONファイルを選びます。件数と注意事項を確認してから復元を実行してください。現在の管理者アカウントは保持され、職員アカウントは必要に応じて登録し直します。既存の利用者・プランがある保存先への上書き復元はできません。

## Excelファイルの移行

管理画面の移行機能で `.xlsm` ファイルを選択し、取り込み前のプレビューを確認します。Excelマクロは実行しません。既存データの取り込みと業務ルールの再現範囲は、画面の案内とプロジェクトのREADMEを確認してください。

## 開発と配布用ビルド

Node.js 24以上を使用します。依存パッケージをインストールし、開発時は次のコマンドを実行します。

```sh
npm ci
npm run dev:desktop
```

配布用インストーラーは次のコマンドで作成します。

```sh
npm run package:windows
```

このコマンドは画面をビルドし、ElectronとNSISを使ってWindows x64インストーラーを `release/` に生成します。生成後にWindows実行ファイル形式、主要ファイル、相対アセット参照、CSP、利用者データの混入がないことを確認し、SHA-256を `release/windows-artifact.json` に記録します。

Linuxからの生成時は、electron-builder 26.15.3がmacOSでも使用する内蔵 `UninstallerReader` でNSISアンインストーラーを取り出します。同版のLinux用Wineバンドルに必要なDLLが含まれないためのビルド時の対応です。依存パッケージや実行ファイルを改変せず、このソフトのNSIS中間ファイルだけを処理します。パッケージャーのバージョン、アンインストーラーのPEヘッダー、NSIS署名を確認し、SHA-256を `windows-uninstaller-check.json` に保存します。electron-builderのバージョン変更時は、この対応を再検証してください。

Windowsでのインストール、アンインストール、起動、共有接続、印刷、ファイアウォール動作はWindows実機で確認してください。`windows-artifact.json` の `windowsRuntimeValidated: false` は、この実機確認がまだ済んでいないことを示します。

Linux版Electronが開発依存パッケージにインストール済みの場合、ビルド後にElectron内蔵NodeとSQLite、生成した `app.asar` 内の保存・API処理、画面アセットの読み込みも確認します。`electron-linux-runtime-check.json` に実際のバージョンと結果を記録します。これはLinuxでの実行確認です。

初版インストーラーにはコード署名を付けていません。WindowsのSmartScreenが発行元未確認の警告を表示する場合があります。正式配布時には組織の署名証明書で署名してください。
