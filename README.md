# CareManager — ケアマネ業務管理ソフト

添付の「M対応ケアマネ業務管理表1.xlsm」を調査して開発した、Windows 10/11・64ビット向けの初版です。Excelを起動せずに、利用者台帳、認定期限、ケアプラン、会議通知、同意書を管理できます。

## Windowsで使う

`release/CareManager Setup 0.1.0.exe` をインストールします。事業所で1台を「共有元」に設定し、ほかのPCは共有元の事業所内IPアドレスへ接続します。職員ごとのログイン、管理者とスタッフの権限、同時編集の競合検出に対応しています。

具体的なインストール、共有、バックアップ・復元手順は [README-WINDOWS.md](README-WINDOWS.md) に記載しています。

## 実装した機能

| 業務 | 初版の機能 |
| --- | --- |
| 利用者台帳 | 居室、カルテ番号、氏名、保険者、介護度、入所日、自立度、担当CM、退所状況 |
| 期間管理 | 作成年月、ケアプラン開始・満了年月、認定期限、元Excelと同じ期限比較 |
| プラン管理 | 作成日・印刷日・会議日・担当・同意書の送付と回収、有効期間の保存 |
| 一括作成 | 作成年月で対象抽出、作成者の巡回割当、人数の均等分割・会議指定・居室A/B振分け |
| 帳票 | 会議のお知らせ1/2回目、包括同意書、身体拘束説明書の表裏、A4印刷とPDF保存 |
| Excel移行 | 確認プレビュー、元号・Excel日付の変換、結合居室の引継ぎ、欠損保持、重複・氏名照合 |
| 事業所内共有 | 共有元PCのSQLiteデータベース、ログイン、職員アカウント、操作履歴、更新の競合検出 |
| バックアップ | JSON書き出しと、利用者・プランが未登録の共有元への復元 |

実際に添付ファイルを読み取り、利用者59件・プラン9件の取り込み、同じファイルの再取込時の重複スキップ、バックアップからの復元を確認しました。これはメモリ内だけで検証し、実データはソースや配布ソフトに含めていません。添付ファイルも変更していません。

## 日付と帳票の扱い

元Excelの認定期限・台帳のプラン期間は年月単位で保持します。開始と終了が逆転している元データは備考へ保持し、期間欄を未確定にして修正を案内します。年のない既存プラン期間や不完全な入所日は、自動で年や日を補いません。

取り込んだプランの同意書を出す前に、プラン編集で開始日・終了日の年月日を確定してください。新しく作成したプランは台帳の開始月1日から満了月末日までを保存し、その後の台帳変更で期間が変わらないようにしています。身体拘束説明書の対象区分もプランに保存します。

身体拘束説明書の理由・方法・時間帯・心身状況・開始解除予定・署名は原本と同じ手書き欄です。ソフトによる臨床判断や電子同意は実装していません。本文は事業所設定で編集できます。文面がA4ページに収まらない場合は出力を止め、調整を案内します。

印刷のキャンセルやPDF保存では印刷日を変更しません。紙に印刷した後、「印刷日を記録」を押します。

## 初版で実装していない範囲

- VBAの期間自動更新、認定満了後の追加3か月行、同じ利用者・対象月に複数の期間を持つプラン。期間は台帳とプランで確認して編集します。
- 居室の2人同時入替。居室は各利用者の編集で変更します。
- 作成済み帳票そのものの履歴保管、電子署名、身体拘束の説明記録の専用入力。
- 常駐Windowsサービス、自動更新、インターネット越しの接続、TLSによる共有通信の暗号化。

共有元のアプリとPCを勤務中起動しておく構成です。初版の共有通信は事業所LAN内のHTTPで、外部のホストへは接続できません。Windowsインストーラーは未署名です。Windows実機でのインストール・共有接続・紙印刷の検証はまだ行っていません。実業務への導入前に、検証用データでその操作を確認し、組織に必要な署名と通信保護を整えてください。

元Excelの構造と移行上の注意は [docs/EXCEL-MIGRATION.md](docs/EXCEL-MIGRATION.md) にまとめています。

## 開発

Node.js 24以上を使用します。Windowsでは次でデスクトップ版を起動できます。

```sh
npm ci
npm run dev:desktop
```

クラウド環境では既存の `/workspace/-` を使用します。新しいGit worktreeを作成する必要はありません。GUIを使わずに開発する場合は、別々の端末で次を実行します。

```sh
# 端末1：共有API。開発用データはGit管理しない .local-data/ に保存
npm run dev:server

# 端末2：画面
npm run dev
```

検証と配布ビルド:

```sh
npm test
npm run build
npm run package:windows
```

Windows用のElectron・NSISアーティファクトは検証付きで取得します。LinuxでのNSIS生成には、固定したelectron-builderの既存アンインストーラー抽出処理を使用しています。生成した実行ファイル・アンインストーラー・アプリ内容を検証し、SHA-256と検証範囲を `release/windows-artifact.json` に記録します。Windows実機検証とLinux上での構造・実行確認は区別しています。

本番依存関係の監査で検出されたExcelJS配下のuuidは、互換性を検証した修正版11.1.1へ固定しています。`npm audit --omit=dev` で既知の脆弱性0件を確認しています。

検証結果と追加画面テストの手順は [docs/VALIDATION.md](docs/VALIDATION.md) に記載しています。
