# Excelからの移行

## 調査した構造

元ファイルには「基本設定」「認定期間管理表」「ケアプラン管理表」「会議のお知らせ（1回目・2回目）」「同意書」「拘束同意書」の7シートがあります。VBAは実行せず、ボタンにつながるM系マクロと帳票の差込処理を読み取りました。

| 元Excel | 移行先と扱い |
| --- | --- |
| 居室A列 | 結合セルの居室を各利用者へ引き継ぐ |
| カルテ番号B列 | 利用者の照合キー。同じ番号と異なる氏名のプランは取り込まず警告 |
| 氏名・保険者・介護度 | 利用者台帳 |
| E〜G列の作成年月 | 一括作成の対象年月 |
| H〜O列のプラン期間 | 年月単位で保持。逆転時は備考に原本値を残し、確認・修正を案内 |
| Q〜S列の認定期間 | 認定期限の年月。元シートには認定開始日がない |
| T〜W列の入所日 | 完全な日付だけ日付欄へ。不完全な値は入所補足に残す |
| X/Y列の自立度 | 障害・認知症の各自立度 |
| Z列の拘束丸印 | 身体拘束説明書の作成対象 |
| プラン表のE/F/G列 | 作成日・印刷日・会議日。General書式のExcel日付シリアルも変換 |
| プラン表のI列の期間 | 年がない文字列は原文を保持し、年を推測しない |
| 基本設定 | 作成者・担当CM・対象年月・第n曜日からの会議日・本文を引き継ぐ |

旧帳票に残る別の利用者情報は台帳へ追加しません。シート間の氏名比較は半角と全角の空白だけを除いて比較し、それ以外の違いは確認事項にします。氏名が空欄の行も適当な名前で登録しません。

初回取り込みで利用者が未登録の場合は事業所設定も取り込みます。利用者が既に登録されている場合は設定を保持します。登録済みのカルテ番号の利用者とそのプランはスキップし、既存データを上書きしません。

## 元Excelの期限表示

元の条件付き書式は「プラン満了年月が認定期限年月以上」で警告し、同月も対象です。現在日からの残り日数による警告は原本にはありません。初版ではこの条件をそのまま使っています。欠損がある場合は比較しません。

## 確認事項

添付の59利用者・9プランは取り込めます。62件の確認事項には、不完全な入所日、年のない有効期間、逆転した台帳期間、第n曜日からの会議日算出などが含まれます。確認事項は取り込み前に表示し、保持できる原情報を補足・備考へ残します。

会議のお知らせに残る旧月日から年を推定して予定を作りません。基本設定の対象年月と第n曜日の指定から算出した会議日と、既存プランに明記された会議日は区別して引き継ぎます。

プランの期間を確定するまでは、同意書を出力できません。年月日を確定した後は、その値をプランに保存して使います。

## 初版とVBAの違い

Excel固有のシート名・列文字・補助列・20行の書込上限は専用画面では使いません。対象利用者の抽出、職員の巡回割当、2会議への均等分割・居室A/B分割、会議通知と同意書は初版に実装しています。

期間自動更新・追加3か月行・同じ対象月の複数期間プラン・2人の居室同時入替は初版には含めていません。元マクロのコメントと実処理が違う箇所も確認しており、追加開発時は実処理を基準にする必要があります。

元データ、職員の実名、施設の固有情報はソースや配布用の検証資料に埋め込んでいません。初回起動では事業所登録を行い、管理者が確認してからExcelを取り込む設計です。
