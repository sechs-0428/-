## 自動テストの再実行

```sh
npm ci
npm test
npm run build
```

追加の画面テストは、PythonとPlaywrightがある開発環境で実行できます。

```sh
python -m pip install playwright
python -m playwright install chromium
python tests/browser-final.py
```

システムのChromiumを使う場合は `--chromium` で実行ファイルを指定できます。新しい隔離データベースと架空のバックアップを毎回作り、検証後にそのテスト用サーバーを停止します。結果と画像はGit管理対象外の `.test-data/browser-final/` に保存します。既定ポート43181が使用中なら `--port` で別のポートを指定してください。

画面テストでは登録、設定の連続保存、復元、二つの会議への一括作成、同時編集の競合と再読込、パスワード変更後の再ログインを確認します。入力エラーと編集競合を意図的に起こす400/409応答は正常な検証結果です。エラーの理由をダイアログ内で読めること、未保存の入力が保持されることも確認します。
